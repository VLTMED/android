# ترجمات واجهة التطبيق

الملف `ui-strings.csv` هو مصدر النصوص التي تظهر في واجهة التطبيق. لإكمال العربية أو مراجعتها، عدّل عمود `arabic_translation` فقط. اترك `key` و`english_source` ومعلومات المصدر كما هي، وحافظ على كل متغير بين الأقواس المعقوفة مثل `{count}` و`{url}` حرفيًا.

لإضافة لغة لاحقًا، أضف عمودًا باسم `translation_fr` (رمز اللغة) أو `french_translation`، ثم املأ الترجمات. يدعم المولّد رموز اللغات الشائعة مثل `fr`, `es`, `de`, `ja`, `ko`, `zh`, `pt` و`tr`، ويُنتج موردًا تلقائيًا عند البناء. يختار التطبيق الترجمة المطابقة للغة التطبيق/الجهاز، ويعود إلى الإنجليزية إذا لم تتوفر ترجمة.

يتحقق `scripts/generate-ui-translations.py` من المفاتيح والمتغيرات ويولّد ملفات الموارد؛ لا تعدّل ملفات JSON الناتجة يدويًا. أسماء الأفلام والقنوات والمواقع ونصوص صفحات الويب والترجمات المعروضة في الفيديو بيانات محتوى وليست نصوص واجهة، لذلك تبقى كما وردت من مصدرها.
